### Изменения в следующей версии:

- Исправлено: в WebUI из версии и названий стратегий пропадали дефисы (`v1.9.6-extended` выглядело как `v1.9.6extended`)
- **Две сборки в каждом релизе**: обычная и **extended** (`-extended.zip`) — та же самая плюс DNS по профилям. Обновления каждая получает по своему каналу, перейти между ними можно установкой другого архива поверх
- **DNS по профилям** (только extended, Настройки → Инструменты): как в Keenetic — свои DoH, DoT, DoQ или обычные DNS-серверы для выбранных доменов и их поддоменов, остальное — через DNS по умолчанию (DNS сети или любой профиль)
- До 32 профилей, до 8 серверов и 1000 доменов в каждом; домены можно добавлять по одному или списком
- Типы серверов: DoH, DoH3, DoT, DoQ, обычный DNS (UDP, длинные ответы по TCP — как в Keenetic), DNS-штампы sdns://
- Пресеты: XBox DNS, Comss.one DNS, GeoHide DNS — с DoH, DoT и обычными адресами
- Режим «Без службы обхода»: DNS работает и когда служба остановлена или на паузе
- Проверка домена из WebUI и предупреждение, если в Android включён «Частный DNS»
- Профили и настройки DNS входят в резервную копию; состояние DNS — в «Диагностике»
- Профили DNS можно выбирать долгим нажатием и удалять сразу несколько
- Журнал DNS — отдельным источником в «Журналах»: запуски, перезапуски, с какими серверами и почему; dnsproxy больше не может остаться «сиротой» на порту при одновременных запусках (из-за этого в журнале появлялось «упал — перезапуск» без перезапуска)
- Исправлено: после быстрого выключения и включения Wi‑Fi пауза в домашней сети оставалась и на мобильной сети. Состояние сети теперь берётся из `cmd wifi`, а через 30 с после смены сети — повторная проверка
- Главный экран: кнопка «Вернуть паузу» после ручного запуска в домашней Wi‑Fi; убраны «Очередь», «Потери» и лимит connmark, в extended показывается, включён ли DNS
- Убран флаг WAKELOCK и строка про conntrack в журнале при каждом запуске
- Положение прокрутки сохраняется при возврате назад: из профиля DNS, из подразделов и из настроек на вкладки
- Лист выбора стратегии: фон размывается, лист закрывается смахиванием вниз с заголовка или с любого места списка, когда он в начале; затемнение и размытие идут за пальцем
- Домашняя Wi‑Fi считается домашней, только пока трафик идёт через неё: если Wi‑Fi подключена без интернета (например, сразу после перезагрузки роутера или телефона) и Android перешёл на мобильную сеть, обход не встаёт на паузу. После загрузки сеть перепроверяется через 30 с. Стратегии по сетям тоже смотрят на сеть, через которую идёт трафик
- Резервные копии — в своей папке `Download/nfqws2` (старые копии из `Download` переносятся туда сами); список копий загружается после выезда листа
- Исправлено: создание копии писало в журнал «printf: Argument list too long», а восстановление из выбранного файла большого архива не работало — большие данные теперь передаются частями
- Исправлено: в фильтре по приложениям при некоторых awk правило получало `--uid-owner ,10201` с лишней запятой
- DNS: watchdog больше не перезапускает работающий dnsproxy, если PID-файл указывает не на него; одинаковые ошибки серверов попадают в журнал DNS раз в 5 минут со счётчиком повторов
- Подписи и пункты WebUI больше не выделяются долгим нажатием (кроме полей ввода и журналов); волна нажатия на чипах «Журналов» не выходит за чип; панель выбора профилей DNS больше не может появиться на другом экране

### Изменения в v1.9.5:

- Поддержка раздачи интернета (Wi-Fi Hotspot, USB-модем, Bluetooth): перехват транзитного трафика в цепочке FORWARD mangle (nfqws_fwd), защита от утечек и блокировка QUIC
- Переключатель раздачи интернета (ENABLE_HOTSPOT) в настройках модуля и WebUI
- Привязка и кэширование стратегий по сетям (NET_STRATEGY): автоматическое запоминание выбранной стратегии отдельно для каждой Wi-Fi сети (по SSID) и мобильного оператора
- Автопереключение стратегий при смене сети на сохранённую для новой сети (в фоне через Netlink ip monitor)
- Твик net.ipv4.tcp_timestamps = 1 для корректной работы десинхронизации/сплиттинга без сброса сессий ТСПУ
- Новые CLI-команды: current-network, list-net-strategies, clear-net-strategies
